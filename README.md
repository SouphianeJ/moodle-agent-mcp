# Moodle Agent MCP

An AI assistant that works in Moodle, with the teacher's rights and never more.

This repository publishes what surrounds the free Moodle plugin `local_mcpcourse` (an MCP server for Moodle 4.1 to 5.3):

- **[`skills/`](skills/)**: six agent skills, one per family of teacher tasks, in the open
  [Agent Skills](https://agentskills.io/specification) format. They are generated by the plugin from its scenario catalog.
- **[`site/`](site/)**: the website, <https://moodle-mcp.petits-detours.fr> (Next.js, static export, French and English).
- **[`deploy/`](deploy/)**: the Caddy block and the deployment script of the site.

## Install the skills

| Assistant | How |
| --- | --- |
| Claude Code | `/plugin marketplace add SouphianeJ/moodle-agent-mcp`, then `/plugin install moodle-agent-mcp@moodle-agent-mcp` ([docs](https://code.claude.com/docs/en/plugin-marketplaces)) |
| claude.ai, Claude Desktop | Download a zip from the [latest release](https://github.com/SouphianeJ/moodle-agent-mcp/releases/latest), then Customize > Skills > Upload a skill ([help](https://support.claude.com/en/articles/12512180-using-skills-in-claude)) |
| ChatGPT (Business, Enterprise, Edu) | Skills > Create > Upload from your computer, with the zip ([help](https://help.openai.com/en/articles/20001066-skills-in-chatgpt)) |
| Codex | Copy a skill folder into `.agents/skills/` or `~/.agents/skills/` ([docs](https://learn.chatgpt.com/docs/build-skills)) |
| Gemini CLI | Copy into `.gemini/skills/` or `~/.gemini/skills/`, or `gemini skills link skills/` ([docs](https://geminicli.com/docs/cli/skills/)) |
| Cursor | Copy into `.cursor/skills/` ([docs](https://cursor.com/docs/skills)) |
| Mistral Vibe Work | Context > Skills > New Skill, paste the `SKILL.md` ([docs](https://docs.mistral.ai/getting-started/quickstarts/vibe-work/create-first-skill)) |

The skills guide the assistant; the connector itself is the plugin, installed in Moodle by its administrator. See the
[installation page](https://moodle-mcp.petits-detours.fr/en/install/).

## Maintain

```bash
scripts/sync-skills.sh <path to local_mcpcourse>   # copy agent-kit/skills, check them, refresh site/data/scenarios.json
node scripts/check-skills.mjs                      # frontmatter, names and lengths per the Agent Skills spec
scripts/build-skill-zips.sh                        # dist/skills/<name>.zip + SHA256SUMS (not committed)
cd site && npm ci && npm run lint && npm run typecheck && npm run build   # site/out/
deploy/deploy.sh --target /srv/moodle-agent-mcp    # build and switch the served release; --rollback to go back
```

The plugin is the single source of the skills and of the scenario list: never edit `skills/` or `site/data/scenarios.json`
by hand. The French titles of the scenarios live in `site/data/scenarios.fr.json`; the lint fails when one is missing.
A tag `v*` runs the release workflow, which attaches the skill zips to the GitHub release.
