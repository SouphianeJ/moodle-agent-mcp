# Skills

One folder per skill, in the [Agent Skills](https://agentskills.io/specification) format: a `SKILL.md` with a YAML
frontmatter (`name`, `description`) followed by the instructions.

These files are **generated by the plugin** (`agent-kit/skills` of `local_mcpcourse`, from its scenario catalog) and
copied here by `scripts/sync-skills.sh`. Do not edit them by hand: change the plugin, then sync.

(see [`../LICENSE-GPL-3.0.txt`](../LICENSE-GPL-3.0.txt)).

Installation for each assistant: see the main `README.md` or the "Skills" page of the site.
